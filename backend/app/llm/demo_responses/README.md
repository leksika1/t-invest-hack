- Балтийский лизинг: порядок оферты дополнен адресной заявкой и альтернативными инструкциями через НРД/номинального держателя, предварительным резервированием и отсылками к Программе — Решение, стр. 9–10. Это приобретение у владельцев, не предварительные договоры размещения.

- Обеспечение не предусмотрено; ковенанты и кросс-дефолт не объявляются наличествующими по шаблонным инструкциям. Законные права владельцев и условность call сохранены.
- Балтийский call: дата 13 февраля 2028 и непогашенная часть номинала подтверждены Условиями размещения, п. 7, стр. 11; нет утверждения о call в любую дату.

Сопоставление только по полному набору sha256; любые другие документы переключают эвристику. В gold исходный номер пункта сохранён. Все положительные ответы проходят обычный verify, включая пересопоставление document_id на новые UUID.
